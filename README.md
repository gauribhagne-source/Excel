 Coffee Shop Sales Analysis | Using Microsoft Excel
 
 Objective 
 The objective of this project is to analyze coffee shop sales data using Microsoft Excel and identify sales trends, top-selling products, product category performance, and store-wise sales performance.

Description 
This dataset contains coffee shop transaction records, including transaction, store, product, price, and sales-related information. It helps analyze sales trends, product performance, and store-wise sales using Microsoft Excel.



| Column               | Description                             |
| -------------------- | --------------------------------------- |
| **Transaction ID**   | Unique ID for each transaction          |
| **Transaction Date** | Date of the transaction                 |
| **Transaction Time** | Time of the transaction                 |
| **Store ID**         | Unique ID of the store                  |
| **Store Location**   | Location of the store                   |
| **Product ID**       | Unique ID of the product                |
| **Unit Price**       | Price of one product unit               |
| **Product Category** | Main category of the product            |
| **Product Type**     | Type of product sold                    |
| **Product Detail**   | Specific name or details of the product |
